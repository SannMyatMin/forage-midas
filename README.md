### Midas 💻
Project repo for the JPMC Advanced Software Engineering Forage program

### Intro 🌿
This project serves as the "Midas" repository, developed as part of the JPMC Advanced Software Engineering Forage program. The aim of this project is to explore and implement modern software engineering practices and adhere to the standards set by JPMC.

### Features ⚡
    1. Microservices Architecture: The system is decomposed into smaller, independently deployable microservices.
    2. Spring Boot Framework: Utilizes Spring Boot for rapid application development and simplified configuration.
    3. RESTful APIs: Implements RESTful APIs for seamless communication and integration with external services.
    4. Unit & Integration Testing: Includes comprehensive unit and integration tests to ensure code quality and reliability.
